## 1. 실험 목적과 확인할 것

입력 조합과 출력의 관계를 **진리표·파형으로 설명**한다. 이 실험의 입출력은 입력 `a, b, c` / 출력 `o[7:0]`(원-핫).

## 2. 예상 입력·출력 (진리표, 비트 순서: MSB가 왼쪽)

| a b c | {a,b,c} | 활성 비트 | o[7:0] |
|---|---|---|---|
| 0 0 0 | 0 | o[0] | 00000001 |
| 0 0 1 | 1 | o[1] | 00000010 |
| 0 1 0 | 2 | o[2] | 00000100 |
| 0 1 1 | 3 | o[3] | 00001000 |
| 1 0 0 | 4 | o[4] | 00010000 |
| 1 0 1 | 5 | o[5] | 00100000 |
| 1 1 0 | 6 | o[6] | 01000000 |
| 1 1 1 | 7 | o[7] | 10000000 |

`o = 8'b00000001 << {a,b,c}`. 8개 조합 전부 TB가 검사한다.

## 3. 직접 작성한 코드와 파일 역할

작성 파일: `src/decoder3x8.v`, `sim/tb_decoder3x8.sv`, `constraints/pins.xdc`

```verilog
// src/decoder3x8.v
module decoder3x8(
    input  wire a,b,c,
    output wire [7:0] o
);
    assign o = 8'b00000001 << {a,b,c};
endmodule
```

**설계 설명.** `o = 8'b00000001 << {a,b,c}`. {a,b,c}를 3비트 이진수로 보고 그 값만큼 1을 왼쪽으로 밀어 정확히 한 비트만 1이 된다.

| 파일 | 역할 |
|---|---|
| `src/*.v` | 설계(RTL). 합성 대상이며 TB를 넣지 않는다. |
| `sim/tb_decoder3x8.sv` | DUT 연결, 입력 자극, 예상값 검사(`$fatal`), `wave.vcd` 덤프(`$dumpfile`·`$dumpvars`), `$finish`. 입력을 10 ns 간격으로 바꾸며 8개 조합을 검사한다. |
| `constraints/pins.xdc` | 보드 핀 배정(PACKAGE_PIN·IOSTANDARD·get_ports). Icarus 기능 시뮬레이션의 입력이 아니다. |
| `simulation.json` | `sources`, `testbench`(`sim/tb_decoder3x8.sv`), `simulation_top`(`tb_decoder3x8`) 지정. |

## 7. 실험 당일 보드 확인 계획

- 장비: Spartan-7 XC7S75 교육용 보드(part `xc7s75fgga484-1`). 연결 전 전원·핀 기능·I/O 전압(LVCMOS33)을 확인하고, 배선 변경은 전원을 끈 상태에서 한다.
- 확인 계획: a,b,c 8가지 조합에서 LED 8개 중 정확히 하나만 켜지고 위치가 이진값과 맞는지 확인한다.
